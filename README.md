# Gridiron AI

An AI-powered college football intelligence platform. It continuously reads the
[CollegeFootballData](https://collegefootballdata.com) feed, detects meaningful changes,
and uses **Groq** to turn them into short, factual explanations.

> The football API is the source of truth. The AI **never** invents a score, stat, ranking,
> injury, commitment or result — when the data doesn't have it, it says so. Predictions are
> always labeled as predictions.

## Features

| Area | What it does |
| --- | --- |
| **Automatic pipeline** | `/api/cron/refresh` polls games, detects score changes / finals / kickoffs / ranking moves, and only then calls the AI. Results stored + surfaced in the ticker and home feed. |
| **Live game analyst** | Every game page has an auto AI read + a "What just happened?" ask box. |
| **AI game summaries** | Generated automatically when a game goes final (turning point, key stat, implications). |
| **Power rankings** | A statistical model (Elo, SP+, win %, point differential, SoS, quality wins, bad losses) produces the ranking; Groq writes one explanation sentence per team. |
| **Daily briefing** | `/briefing` — top stories, games to watch, outlook, personalized to your starred teams. Regenerated by `/api/cron/briefing`. |
| **Team reports** | `/teams/[name]` — strength, weakness, player/unit to watch, most important game, playoff outlook, from real data. |
| **Matchup predictor** | Elo win-probability model + AI explanation. The number is math, not the LLM. |
| **Gridiron AI chat** | `/chat` — retrieval-grounded, context-aware (resolves "they"/"their" across turns), personalized. |
| **Explain this** | `ExplainButton` anywhere — Quick / Normal / Deep Dive. |

## Run locally

```bash
npm install
cp .env.example .env.local   # fill in CFBD_API_KEY and GROQ_API_KEY
npm run dev
```

Only `CFBD_API_KEY` and `GROQ_API_KEY` are required. Supabase is optional — without it the
app uses an in-memory cache and still works fully. To enable persistence + realtime, run
`supabase/schema.sql` and set the `NEXT_PUBLIC_SUPABASE_*` / `SUPABASE_SERVICE_ROLE_KEY` vars.

## Deploy (Vercel)

1. Import the repo, set the env vars from `.env.example`.
2. `vercel.json` already defines the crons (`/api/cron/refresh` every 5 min, `/api/cron/briefing` daily).
3. Set `CRON_SECRET` and Vercel will send it as the `Authorization` header.

## AI provider

`src/lib/ai.ts` is a provider abstraction. `AI_PROVIDER=groq|gemini|openrouter` — Groq is primary,
the rest are drop-in (OpenAI-compatible). Nothing else in the app imports a provider directly.

## Data / source-of-truth hierarchy

1. CollegeFootballData API — games, scores, stats, rankings, Elo, recruiting, portal
2. Database (Supabase) — cached application + AI content
3. AI — analysis and explanation only
